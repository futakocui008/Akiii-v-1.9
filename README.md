# Akiii 回复器 v2.0

Akiii 回复器是一个用于 X / Twitter 的 Chrome 扩展。

## v2.0 更新

- 新增日语回复支持（自动检测平假名/片假名）
- 新增阿里云百炼 API 支持
- 优化回复语气（真实口语化，加入参考样例）
- 新增日文字符数上限设置

## v1.9 更新

- 融入半透明二次元初音风底图
- 整体 UI 升级为高端玻璃拟态设计
- 设置页顶部保留：作者：Akiii | @Guomin184935
- 生成后先进入「可编辑草稿窗」
- 可先手动修改，再点击「填入 X」
- 只填入回复，不自动发送
- 英文推文自动使用英文回复
- 中文推文自动使用中文回复
- 继续支持 OpenAI / API2D / 兼容 Chat Completions
- `fk` 开头 Key 自动识别为 API2D

## 安装方式

1. 解压 zip
2. 打开 Chrome：`chrome://extensions/`
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `akiii-reply-extension-v19` 文件夹
6. 点击插件图标，填写 API Key 并保存
7. 刷新 X 页面使用

## 使用方式

- 时间线推文旁边会出现 `AI回`
- 打开回复框后，工具栏旁边会出现 `AI填入`
- 点击生成后，会弹出可编辑草稿窗
- 改满意后，再点击 `填入 X`
